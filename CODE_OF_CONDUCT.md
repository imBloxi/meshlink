# Code of conduct

MeshLink exists so that people can talk freely. The same applies here.

- Be respectful. Criticize code and ideas, not people.
- No harassment, insults, or discrimination of any kind.
- Assume good faith, and help newcomers.
- Do not share other people's private information.
- Do not use this project's spaces to plan harm to anyone.

Maintainers can edit or delete comments, close issues, and block people who break these rules.

To report a problem, contact the maintainers privately through a GitHub security advisory (the same form as in [SECURITY.md](SECURITY.md)) and add "conduct" to the title. Reports stay confidential.
